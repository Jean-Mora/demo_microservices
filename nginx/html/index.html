Dos microservicios en Kotlin + Spring Boot, detrás de un reverse proxy nginx, autenticados con JWT de AWS Cognito. Estudien este repo: aquí está, en pequeño, casi todo lo que vamos a discutir en el curso.

Ojo: sin Authorization: Bearer <access_token> todo responde 401. Eso es a propósito.

Lo que quiero que se lleven

  • Quién eres lo dice el token, no el cliente. Ningún endpoint recibe tu id como parámetro.
  • Autenticar ≠ autorizar. Spring Security valida la firma del JWT y dice "adelante"; saber de quién es la fila 1 es tu trabajo.
  • El access_token es una llave; el id_token es una cédula. Por eso /diary/me devuelve email: null.
  • Sin roles también hay autorización. Todos los usuarios tienen los mismos permisos y aun así nadie lee el diario de otro.
  • Un if borrado = un IDOR (OWASP #1, Broken Access Control). Los tests existen para que ese bug no vuelva.

"Todos los usuarios de este sistema tienen exactamente los mismos permisos. Y aun así, ninguno puede leer el diario de otro. Spring Security no tiene absolutamente nada que ver con eso."
